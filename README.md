# Simulation: by Thomas Wellmann da Riva Cesar

# 

# Eine Dungeon über Wasser! Nach jeden Tag was neues zu Tun. 4 Arten von Räume: 

# \-Leeres Raum (hier passiert nichts);

# \-Looting Raum (nachdem man ein durchgeht und zurück zum shop kommt, bekommt der MC mehr Leben);

# \-Gegner Raum (3 Gegner zu besiegen. Jeder kill kann im shop für mehr hit-Schaden bekommen);

# \-Boss Raum (Prinzipiell gleich wie Gegner Raum, nun 1 stärker Gegner);

# 

# Zwischen 22 und 6 Uhr schläft der MC und es wird windig.

# MC Navegation-System nicht 100%.

# Mit 'Space' man kann die Kamera freischalten, oder im MC wieder fixieren.

#
